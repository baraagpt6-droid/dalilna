Dalilna 1.8.2
Application release: PWA + Android WebView
Android versionCode: 167
Web app version: 1.8.2
Live place discovery: Geoapify Places with OpenStreetMap-based fallbacks and provider attribution.
Shared marketplace: PostgreSQL API with schema version 2, including opening_hours, website, latitude and longitude.
New community listings are submitted as pending and appear publicly only after server-side admin approval.
Legacy local listings must be migrated from each device using “نقل إضافاتي القديمة للمراجعة”. clientRef uniqueness prevents duplicate database records on retry.
Server configuration: DATABASE_URL and DALILNA_ADMIN_TOKEN must be stored as server environment secrets, never in the client or APK.
Android APK: debug-signed testing build only; not a Google Play production release.
