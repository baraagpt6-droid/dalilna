Dalilna 1.5.5
Application release: PWA + Android WebView
Backend directory API service version: 1.5.0 (separate service package version)
Gemini cloud assistant (optional, server-side)
Assistant replies disclose source: Gemini, fixed administrative reference, local, or cloud fallback
Ibb has 20 districts; Hubaish has 22 sub-districts
Offline local assistant remains available.
Admin login is directly visible in the account menu; the logo long-press shortcut was removed.
Admin root credential reset applied once through adminCredentialVersion=2.

Regional profiles, population projections, map searches, local photos and likes. Local directory searches now offer a Google Maps fallback when no listing is stored on the device.

Admin review requests are surfaced in a full-width dashboard shortcut; pending rows show shop details and explicit approve/reject actions.

Live place discovery is sourced from OpenStreetMap on selected governorate/district or user-approved GPS location. Results show attribution and are not copied into local user listings.
Google Places is not enabled until a restricted billing-enabled API key is configured.

Live place search uses the Vercel Node Function as primary, with a 35-second client timeout, retry action, and Google Maps fallback.

Live place discovery now queries Nominatim and Overpass directly from the browser. Geocoding is throttled to one request per 1.1 seconds and cached. Overpass has two public endpoints. The interface has a 30-second timeout and retry plus Google Maps fallback.

Live search uses the shared Render API proxy. Nominatim and Overpass requests are globally serialized per API process at 1.1-second intervals, with caching. The browser checks /health before searching and allows up to 100 seconds for free-service wake-up, then offers retry and Google Maps fallback.

Live directory search v1.5.5
- Google Places API (New) is the preferred live source when GOOGLE_PLACES_API_KEY is configured on Render.
- OpenStreetMap remains the fallback.
- Google Places results are live-only and are not saved in local listings or cached.
- Empty live searches offer a direct Google Maps search action.
- Changing a selected region clears old GPS coordinates.
