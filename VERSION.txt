Dalilna v2.8.0
Release date: 2026-11-23

- Adds an in-memory nationwide search index for all 22 Yemen governorates.
- Keeps live map fallback requests short and independent from local search.
- Adds near-name suggestions when an exact local match is unavailable.
- Removes synthetic marketplace entries and blank-image placeholders.
- Adds WhatsApp sharing for actual approved marketplace listings.
- Filters expired and duplicate job records before publishing the six-hour feed.
- Aligns PWA, Android and API version metadata at 2.8.0.

Marketplace inventory is made only from approved user adverts or authorised merchant feeds.
Open-map records are not marked as field-verified unless Dalilna has verified them.
The Android APK generated by CI is a debug-signed testing build, not a Play Store production release.
