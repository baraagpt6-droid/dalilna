Dalilna v3.0.1
Release date: 2026-11-23

- Fixes assistant job-feed expiry handling so shared jobs are read from jobs-feed.json instead of falling back to the local empty list.
- Shows the five newest active jobs with city, organization, a direct source/application link and a save-to-favorites action.
- Adds conversation context for follow-up questions about the last selected job or directory result.
- Uses one horizontal source badge at the top of assistant messages and a vertical bubble layout to prevent overlap.
- Adds a Netlify static-site build that publishes only allow-listed PWA assets and regional JSON files.
- Adds an optional GitHub Actions Netlify deployment workflow while keeping GitHub Pages and Render as fallback services.
- Aligns the PWA, Android, package, manifest and OTA release metadata at 3.0.1.

Netlify deployment requires a Netlify site ID GitHub repository variable and a Netlify auth token GitHub repository secret. The final .netlify.app site name is reserved by the Netlify account owner and must be checked for availability before it can be adopted.

The Android APK is a persistent-key-signed debug/test build for direct installation. It is not a Google Play production release.
