إعداد مشروع دليلنا من الهاتف فقط
=================================

ما جهزته داخل هذا الأرشيف:
- تطبيق PWA كامل في جذر المشروع.
- مشروع Android WebView يضم ملفات التطبيق ويعمل محلياً دون إنترنت بعد فتحه.
- GitHub Actions لبناء APK تجريبي موقّع تلقائياً بمفتاح debug.
- GitHub Actions لنشر PWA على GitHub Pages كرابط الويب الرسمي الأساسي، مع بقاء Netlify كاستضافة ثانوية.
- إعدادات Vercel إذا توفرت صلاحية إنشاء مشروع هناك.

لماذا لم أرفع المستودع بنفسي؟
حساب GitHub المتصل هو baraagpt6-droid، وتثبيت GitHub المتاح مضبوط على مستودع محدد واحد هو baraa-money-tracker. لا تتوفر في أدوات GitHub المتصلة هنا عملية إنشاء مستودع جديد. لن أضع دليلنا داخل مشروع المصروفات لأنه مشروع مختلف. كما رفض Vercel إنشاء المشروع بسبب صلاحية 403 (Create Project غير مسموحة للحساب المتصل).

الخطوة اليدوية الوحيدة المطلوبة لفتح مساحة GitHub جديدة:
1. افتح https://github.com/new من متصفح Huawei.
2. أنشئ مستودعاً باسم dalilna. اجعله Public حتى يستطيع صديقك رؤية الكود. اتركه فارغاً (لا تضف README أو License).
3. بعد إنشاء المستودع، افتح إعداد GitHub App من الرابط التالي وأضف مستودع dalilna إلى المستودعات المسموحة:
   https://github.com/settings/installations/183838530
   اختر Configure ثم Repository access ثم أضف dalilna.
4. ارجع إلى ChatGPT وأرسل رابط المستودع. عند ظهوره في الاتصال أستطيع رفع الملفات إلى هذا المستودع بأدوات GitHub.

بعد رفع الملفات إلى GitHub:
أ) للنشر على الويب:
- افتح Settings ثم Pages.
- اختر Source = GitHub Actions.
- شغّل Workflow Deploy Dalilna PWA من تبويب Actions.
- رابط الويب الأساسي الرسمي هو https://baraagpt6-droid.github.io/dalilna/. يبقى Netlify عنواناً ثانوياً.

ب) لبناء APK:
- افتح Actions.
- اختر Build Dalilna Android APK.
- اضغط Run workflow.
- انتظر اكتمال البناء.
- افتح نتيجة التشغيل ثم Artifacts ونزّل dalilna-1.2.0-android-debug.zip.
- فك ضغطه على الهاتف وافتح app-debug.apk للتثبيت.

ملاحظات مهمة:
- بيئة العمل الحالية لا تحتوي Android SDK أو Gradle، لذلك لم أستطع إنتاج APK محلياً.
- ملف APK الذي ينتجه GitHub Actions هو Debug APK موقّع بمفتاح Debug تلقائي، مناسب للتثبيت والاختبار وليس للنشر التجاري في Google Play.
- لا ترفع مفتاح توقيع خاص أو كلمة مروره إلى مستودع عام.
- المساعد المحلي يعمل دون مفتاح API. المساعد السحابي يتطلب OPENAI_API_KEY كمتغير سري في إعدادات الاستضافة ويترتب عليه استخدام مدفوع منفصل.
- حسابات التاجر والمشرف والبيانات المخزنة محلياً لا تزال نموذجاً أولياً؛ تشغيل الدليل تجارياً يتطلب خادماً ومصادقة وقاعدة بيانات مركزية.
