### Third-party data flows

1. **Google Mobile Ads SDK** — IP address, app/ad interactions, diagnostics and performance data, Android Advertising ID, App Set ID and applicable device/account identifiers. Google identifies these as automatically collected and shared for advertising, analytics and fraud prevention; transport is TLS.
2. **WebView/system speech recognition** — optional audio after the user taps the microphone, accepts the disclosure and grants Android permission. The recognition provider may receive audio. Dalilna does not receive or store the raw audio.
3. **Google Gemini** — optional question and relevant general context after the user enables cloud assistant mode. The API request sets `store: false`.
4. **Places/search** — local directory first; Geoapify when the server key is configured; OpenStreetMap Nominatim, Photon by Komoot and Overpass mirrors as live/fallback providers. Search text, selected place/area, category and, for nearby search, coordinates/radius may be sent.
5. **Wikimedia Commons** — search term for the optional place-photo feature.

### Logs, database and retention

The Node.js server logs search text, place/area, category and request origin for selected search-start events, plus operational counts, errors and UGC report metadata. It does not log raw voice audio or full listing bodies as ordinary request logs. Shared listings, photos, submitted contact details, job-seeker profiles and UGC reports are stored in PostgreSQL. Souq/land listings usually expire from public view after 60 days; jobs expire on deadline or after 60 days; job-seeker profiles expire after 60 days. **Expiry hides records; it does not delete rows.** The source has no scheduled purge for expired rows, and some listing categories can have no expiry. Render log retention and PostgreSQL backup retention are provider/account settings, not configured by the app code.

### Accounts and deletion

- No central customer or merchant accounts are created.
- No central account deletion flow exists.
- Shared submissions can be reviewed/removed upon a request to `dalilnasupport@gmail.com`; the app owner/team handles it manually.
- Clearing app data or uninstalling removes local profile/preferences/favourites; it does not remove a submitted server listing.
- Do not promise immediate removal from service logs or backups; their retention is provider-controlled.

### Items not used in the current app

- No in-app direct messaging.
- No in-app marketplace payment, banking, lending, investment or gambling features.
- No contacts, calendar, health or SMS access.
- No Firebase Analytics, Firebase Authentication or Firebase Crashlytics SDKs.
