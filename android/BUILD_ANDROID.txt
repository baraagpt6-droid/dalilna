Android wrapper
===============

Application ID: ye.dalilna.app.debug (debug build)
Version: 3.1.0 (versionCode generated by CI)
Minimum Android: 7.0 / API 24
Target SDK: 36

Release builds also use Google Mobile Ads 25.5.0 and UMP 4.0.0; release signing uses R8 with app-specific keep rules. A real AdMob App ID and banner unit ID are required for the release AAB. Debug builds use Google's official test identifiers.

The Android app uses AndroidX WebViewAssetLoader and the PWA files embedded under app/src/main/assets. CI copies the root PWA assets into that directory before building.

Build command (requires JDK 17, Gradle 8.11.1, Android SDK 36):
  gradle --no-daemon :android:app:assembleDebug

Output:
  android/app/build/outputs/apk/debug/app-debug.apk

CI requires the four persistent signing secrets. The generated APK is a persistent-key-signed debug/test build for direct installation, not a Google Play production release. Never commit a keystore or passwords to this repository.
