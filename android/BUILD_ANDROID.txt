Android wrapper
===============

Application ID: ye.dalilna.app.debug (debug build)
Version: 1.9.1 (versionCode 181)
Minimum Android: 7.0 / API 24
Target SDK: 35

The Android project embeds the PWA files under app/src/main/assets and opens them using AndroidX WebViewAssetLoader at the secure appassets origin. LocalStorage persists in the WebView profile. The shared marketplace client calls the Dalilna Render API over HTTPS. The regional place catalogue is bundled under assets/regional-catalog and loaded per governorate; individual map links are optional.

Build command (requires JDK 17, Gradle 8.9, Android SDK 35):
  gradle --no-daemon :android:app:assembleDebug

Output:
  android/app/build/outputs/apk/debug/app-debug.apk

Debug APKs are for testing. A production APK requires a private release keystore and a controlled signing process. Never commit a keystore or passwords to this repository.
