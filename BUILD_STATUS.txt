Dalilna 1.9.0 — Build and deployment status
===========================================

- Main source release: 1.9.0 (Android versionCode 180).
- Place discovery no longer depends on live Geoapify, Nominatim, Photon, or Overpass requests from the app's primary directory screen.
- A static regional catalogue is built from the Geofabrik Yemen OpenStreetMap extract. The build creates a manifest and 22 per-governorate JSON files and refuses to publish an empty catalogue.
- Scheduled refresh: weekly via .github/workflows/refresh-regional-catalog.yml. The workflow checks the administrative source, builds a new snapshot, commits changed files, and triggers web and Android deployment workflows.
- OpenStreetMap-derived records use ODbL-1.0 attribution. Administrative reference data comes from Open Admin Data Yemen under CC BY 4.0.
- Administrative polygon assignments are preferred when a matching polygon exists. Nearest-centroid fallbacks are explicitly labelled approximate, not official boundary verification.
- The catalogue may be incomplete because not every business or public facility is mapped in OpenStreetMap. A missing result is not evidence that the business or facility does not exist.
- Individual place cards keep optional map links. Maps are no longer queried to populate the app's regional directory.
- User-added shops, jobs, vehicles, products, real estate, and rental adverts remain in the shared PostgreSQL marketplace and require admin approval.
- The production Neon project dalilna-production-frankfurt uses marketplace schema version 2. Marketplace records were empty during the previous review; legacy entries must still be migrated from each device.
- Render dalilna-live remains the shared marketplace API. The old Render directory API and static site are retained until compatibility is confirmed.
- Vercel build checks previously showed build-rate-limit errors; the local catalogue avoids using Vercel as a live map-search dependency.
- Android is a debug-signed testing build. Production signing and Play Store publication remain separate tasks.
