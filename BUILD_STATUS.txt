Dalilna 1.5.9 — Build and deployment status
===========================================

Application
- Progressive Web App and Android WebView.
- Android workflow builds a debug-signed testing APK, not a Play Store production package.
- Root and Android WebView assets must stay synchronized.
- Privacy Policy and Terms pages are included in PWA and Android assets.

Free live directory
- OpenStreetMap Nominatim resolves selected Yemen regions.
- OpenStreetMap Overpass searches FOSSGIS, Private.coffee and VK Maps in sequence.
- The server retries when a provider is busy, times out, returns an Overpass remark, or returns malformed content.
- Results show only fields recorded in OSM. Missing details are not inferred.
- Wikimedia Commons is queried only when the user requests photos. The card shows source page, author and license metadata when provided.
- Place ratings and user-added photos are saved locally on the current device. They are not synchronized or shared in this release.
- Google Places search, details and photo API routes have been removed.
- No paid Google API key, card, or billing account is needed.

Usage and verification
- Public Nominatim, Overpass and Wikimedia Commons endpoints apply fair-use rules and request limits. Availability is not guaranteed.
- The service caches results, throttles requests and retries multiple Overpass mirrors.
- Zero results mean no matching mapped features were returned for that query. It does not prove a business does not exist.
- Check each Wikimedia Commons file page and license before reuse.
- OpenStreetMap attribution is displayed in the search UI and documented in the app.

Security and operations
- User accounts, admin roles, moderation, ratings and contributions remain device-local. This release does not provide a shared multi-user database.
- Do not store secrets in client files or public GitHub content.
- A private Android release keystore and field testing are still required for a Play Store production release.
