Dalilna 2.4.0 — Release readiness
====================================

Implemented in feat/dalilna-root-fix-v2.4.0:
- Shared OSM Category Mapping Dictionary for build-time classification and live Overpass filters.
- Multi-category tagging for overlapping services such as pharmacies.
- Bilingual search text (Arabic/English labels and names), activity tags, governorate, district and neighbourhood.
- Yemen ADM2 Polygon matching from geoBoundaries (335 districts) plus OSM admin boundaries. Approximate nearest-centroid assignments are clearly marked and counted separately.
- Removal of the old map-place/restaurants panel from Souq. Shared PostgreSQL product ads are the only products source.
- Seven product groups: electronics, vehicles, property, solar, home, agriculture, clothing.
- Authenticated merchant JSON feed ingestion with idempotent upserts. Incomplete, invalid or oversized snapshots do not archive previously active ads.
- Daily GitHub Actions refreshes for regional OSM catalogue and jobs; daily product feed workflow to be added.
- Daily Render cron entry point uses scripts/daily-sync.cjs and needs product feed URLs/token for actual merchant product ingestion.
- PWA/Android release metadata 2.4.0 / versionCode 240.

Data notes:
- Current GitHub Pages catalogue will not change until the daily/commit-triggered regional build completes and publishes the new generated files.
- The current stored catalogue on main still needs a 2.4.0 refresh with the category mapping and ADM2 polygon inputs.
- No merchant JSON feed providers are configured in the repository yet. Marketplace importer will correctly skip product ingestion until feed URLs and token are configured; it will not manufacture product ads.
- Jobs are collected from configured official/RSS sources and YemenHR public feed; no direct apply URL is claimed unless the domain is verified.
- The user registration model does not exist in the current marketplace schema. Listing expiry is currently 60 days from each listing's creation time, not account registration.

Verification:
- Awaiting PR validation, daily catalogue refresh, GitHub Pages deploy and Android APK build.
