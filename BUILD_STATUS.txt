Dalilna 2.3.0 — Build and deployment status
=============================================

Release target: 2.3.0
Android versionCode: 230
Web version: 2.3.0

Changes prepared in branch feat/dalilna-global-search-market-fx-v2.3.0:
- Global search across all 22 Yemen governorate catalogue files without a required governorate selection.
- Arabic search normalization for Alif variants, taa marbuta/ha, alif maqsura/ya, diacritics and the definite article.
- Category selection displays matching regional-catalogue locations without requiring a governorate filter.
- Souq has a distinct commercial-place directory sourced from OpenStreetMap. It is filtered by governorate/category and loads only when the Souq screen opens.
- Approved user-submitted marketplace adverts remain separate from map directory records. Map records do not claim product stock, a current selling price or a verified seller.
- Exchange rates and gold are read from the public ye-rial.com current API. Readings older than 24 hours or missing required USD/SAR/21K gold values are hidden; no hard-coded device values are displayed.
- The governorate/district scope label no longer repeats the same governorate name.
- PWA cache namespace and asset versions are updated to 2.3.0.
- Android versionCode/versionName are 230/2.3.0. WebView HTTP cache is cleared once on app-version upgrades while local user data is preserved.
- Android CI synchronizes current PWA and regional-catalogue assets before building the debug APK.

Current source catalogue snapshot:
- 14,886 OpenStreetMap place records.
- 22 governorates.
- 335 districts.
- Snapshot date: 2026-11-22.

Validation and release status:
- CI, PWA deployment and Android APK build have not yet run for this branch.
- Product-stock feeds are not connected. Live inventory and merchant prices must be supplied by a verified merchant integration or approved listings.
- Android APK remains a debug testing package, not a Play Store production-signed release.
