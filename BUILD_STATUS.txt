Dalilna 2.4.0 — Release readiness

Version identifiers:
- PWA: 2.4.0
- Android versionName: 2.4.0
- Android versionCode: 240
- Service worker cache: dalilna-pwa-v2.4.0

Code changes prepared on feat/dalilna-root-fix-v2.4.0:
- Dictionary-driven OSM category classification and multi-category memberships.
- Search all 22 governorate catalogue shards by Arabic/English name, activity tags, address/neighbourhood and administrative names.
- Search/category matching uses normalized Arabic tokens and explicit category membership rather than Arabic label-only matching.
- Refresh and point-in-polygon assignment use Yemen geoBoundaries ADM2 polygons (335 districts), with centroid assignments explicitly marked approximate.
- Souq is separated from the OSM place directory and contains seven product groups only.
- Daily merchant JSON feed import is authenticated, idempotent and snapshot-safe.
- Daily workflow checks live exchange quotes, marketplace DB and jobs endpoints; regional and jobs workflows run separately every 24 hours.
- Android WebView cache invalidates once per installed APK version and preserves user localStorage.

Known data/configuration constraints:
- No merchant JSON feed URL was configured when this code was prepared. Product feed automation remains dormant until merchant endpoints and the shared sync token are configured in Render and GitHub Actions.
- OpenStreetMap contains mapped and named records, not every real business. A category can still have zero matches where the source has no corresponding mapped records.
- District counts report polygon-derived assignments separately from nearest-centroid estimates. Empty districts are not filled with fabricated records.
- Job feeds retain source links; application buttons are only rendered for approved official provider hosts.
- The Android artifact is a debug/testing APK, not a Play Store production-signed package.

The PR and its CI/build/deployment results must be checked before calling this release deployed.
