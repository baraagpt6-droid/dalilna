قيود الأمان والتشغيل — إصدار 2.6.1
====================================

1. تسجيل العميل وبعض الأدوار القديمة ما زال محلياً على الجهاز. هذا ليس نظام هوية خادمي متكاملاً.
2. الإعلانات الجديدة في السوق المشترك تدخل حالة pending ولا تظهر للعامة قبل اعتماد المشرف.
3. تستخدم مراجعة الإعلانات المشتركة الرمز DALILNA_ADMIN_TOKEN المحفوظ في بيئة الخادم. لا تضف الرمز إلى Git أو index.html أو APK أو localStorage أو URL.
4. رمز الإدارة المشترك لا يعادل حسابات فردية للمشرفين أو نظام صلاحيات RBAC كاملاً.
5. رقم الهاتف أو العنوان الذي يرسله المعلن ليس إثبات هوية. لا يوجد OTP للتحقق من كل رقم في هذه النسخة.
6. اعتماد الإعلان يعني السماح بنشره فقط. لا يعني أن فريق دليلنا تحقق ميدانياً من رقم الهاتف أو العنوان.
7. سجلات OpenStreetMap وOverture Maps قد تكون ناقصة أو قديمة. وجود السجل لا يثبت صحة الهاتف أو العنوان، وغياب السجل لا يثبت عدم وجود النشاط.
8. يحفظ فهرس الأماكن مصدر كل سجل وترخيصه. بيانات OpenStreetMap المشتقة تلتزم بمتطلبات ODbL-1.0، مع الاحتفاظ بتراخيص سجلات Overture وFoursquare حسب المصدر.
9. عند عدم توفر مضلع مديرية مطابق، يستخدم بناء الفهرس أقرب مركز إداري ويعلّم التوزيع بأنه تقريبي. لا يعرضه على أنه حد رسمي.
10. استيراد Foursquare المستقل اختياري. لا يدّعي التطبيق استخدام تصدير مستقل ما لم تضبط أسرار التصدير ورمز الوصول في GitHub Actions.
11. الوظائف القادمة من المصادر العامة يجب أن تعرض رابط التقديم الأصلي. قد لا تتضمن كل المصادر وظائف نشطة في كل تشغيل.
12. أسعار الصرف والذهب تخضع لتوفر المصدر وحداثته. يخفي التطبيق البيانات التي لا تجتاز فحص الحداثة بدلاً من اعتبارها أسعار اليوم.
13. المساعد المحلي محرك بحث ومطابقة وليس نموذجاً توليدياً. المساعد السحابي لا يعمل إلا بعد موافقة المستخدم.
14. عند تفعيل Gemini، يرسل التطبيق السؤال وسياقاً من بيانات الدليل العامة ذات الصلة إلى Google عبر الخادم. لا ترسل بيانات شخصية أو حساسة.
15. مفتاح Gemini ورموز الإدارة والمزامنة تبقى في بيئة الخادم أو GitHub Secrets فقط. لا تحفظها داخل ملفات الواجهة أو Android.
16. محددات الطلب الحالية محلية لكل عملية خادم وليست محددات مركزية مشتركة بين نسخ متعددة.
17. لم يُجرَ اختبار اختراق خارجي أو اعتماد أمني مستقل. قبل الإطلاق التجاري أضف مصادقة مركزية وRBAC وسجل تدقيق ونسخاً احتياطياً ومحددات معدل مشتركة ومراجعة أمنية.
18. راقب إعداد DATABASE_URL في Render وتأكد أنه يشير إلى قاعدة PostgreSQL الإنتاجية ذات المخطط المتوقع. راجع النسخ الاحتياطي والاحتفاظ بالبيانات لدى مزود قاعدة البيانات قبل الاعتماد التجاري.
19. مدة الإعلان المجاني المحلي (60 يوماً) تبدأ من أول تشغيل للتطبيق على الجهاز، لأنها لا ترتبط حتى الآن بحساب مستخدم مركزي. لا تعتبرها مدة حساب موثّق. أما إعلانات السوق المشتركة فتبدأ مدة صلاحيتها بعد اعتماد الإدارة ونشرها.

## الإصدارات والاختبارات

- إصدار الواجهة والتطبيق: 2.6.1.
- GitHub Actions يتحقق من مزامنة PWA وAndroid، واختبارات JavaScript وPython، ومسارات API المحلية.
- فحوص الخدمة الحية تعمل ضمن أحداث push إلى main ولا تعمل كلها ضمن pull request.
- لا تعتبر نجاح الاختبارات دليلاً على اختبار اختراق أو على التحقق الميداني من بيانات المحلات.
