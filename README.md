# دليلنا | Dalilna

دليل الخدمات والمحلات والوظائف وسوق البيع والشراء في اليمن. الإصدار الحالي 3.1.0.

## GitHub Pages official hosting

The official PWA is published on GitHub Pages at https://baraagpt6-droid.github.io/dalilna/. Netlify remains a secondary legacy host; its static build checks that the targeted badge-removal CSS/JavaScript guard is present before publishing.

The official browser and PWA URL is https://baraagpt6-droid.github.io/dalilna/. The Netlify host https://dalilna-ftny.netlify.app/ remains a secondary entry point with a targeted badge guard. Render allows the GitHub Pages origin for assistant API requests.

## المنصات والبنية

- Web: تطبيق PWA الرسمي القابل للتثبيت: https://baraagpt6-droid.github.io/dalilna/
- Android: تطبيق WebView يستخدم ملفات الواجهة الموجودة في \`android/app/src/main/assets/\`.
- API: خادم Node.js على Render. العنوان الأساسي للمساعد والخدمات المشتركة هو \`https://dalilna-live.onrender.com\`.
- Static hosting: GitHub Pages هو النطاق الأساسي الرسمي، وNetlify استضافة ثانوية.
- Version source: ملف \`version.json\` وملف \`android/app/build.gradle.kts\`.

## الميزات

- دليل وطني للمحلات والخدمات في المحافظات اليمنية الـ22، مع فهرس بحث خفيف مضغوط يُحمّل عند بدء التطبيق ويعمل من الذاكرة دون انتظار IndexedDB.
- البحث المحلي أولاً من الفهرس الوطني الكامل، ثم Nominatim وOverpass عند عدم وجود نتيجة محلية، بمهلة 3 ثوانٍ لكل طلب.
- سوق مشترك للإعلانات والمنتجات والعقارات والمركبات والوظائف.
- سبع مجموعات سوق: الإلكترونيات، المركبات، العقارات، الطاقة الشمسية، المنزل، الزراعة، والملابس.
- أسعار صرف وذهب، مع إخفاء الأسعار القديمة بدلاً من عرضها كأنها محدثة.
- مساعد محلي ومساعد Gemini سحابي اختياري بعد الموافقة، مع بطاقات اتصال وخريطة وطلبات أسعار الصرف من القراءات المتاحة.
- ملف محلي يعرض تفضيلات الجهاز والإعلانات والمفضلة؛ لا يمثل نظام هوية أو توثيق مركزي للمستخدمين.
- تمييز مصدر الإجابة، ومصدر كل سجل، وحالة التحقق. اعتماد الإعلان يسمح بالنشر ولا يثبت صحة الهاتف أو العنوان ميدانياً.

## دليل الأماكن ومصادر البيانات

يُبنى الفهرس من:
- OpenStreetMap، بترخيص ODbL-1.0.
- Overture Maps Places، مع الاحتفاظ بترخيص مصدر السجل حسب بيانات المصدر.
- Foursquare Open Places المستقل اختيارياً عند توفير رابط التصدير ورمز الوصول. سجلات Foursquare الموجودة داخل Overture تبقى مميزة كمصدرها.

يغطي مرجع التقسيم الإداري 22 محافظة و335 مديرية. تُستخدم حدود المديريات عند توفر مضلع مطابق. إذا لم يتوفر المضلع، يُستخدم أقرب مركز إداري وتُوسم النتيجة بأنها تقريبية.

يُعاد بناء فهرس الأماكن تلقائياً كل ست ساعات من GitHub Actions. عدم ظهور مكان في الفهرس لا يعني عدم وجوده في الواقع. راجع \`DATA_SOURCES.md\` لتفاصيل المصادر والتراخيص.

## الوظائف والسوق

- الوظائف العامة تُجمع من المصادر المسموح بها، وتُرفق برابط التقديم الأصلي عند توفره.
- إعلانات المستخدمين والتجار تدخل قاعدة البيانات المشتركة بحالة مراجعة، ولا تظهر للجمهور قبل اعتمادها.
- استيراد مخزون التاجر لا يبدأ إلا بعد توفير عناوين JSON العامة ورمز المزامنة. راجع \`MERCHANT_FEED_SETUP.md\`.
- لا يُنشئ التطبيق مخزوناً أو أسعاراً أو أرقام تواصل من بيانات الخرائط.

## المساعد الذكي

المساعد المحلي يبحث في بيانات الجهاز ولا يحتاج إلى مفتاح API. المساعد السحابي يستخدم Gemini بعد موافقة المستخدم، ويعمل عبر Render أولاً ثم يحاول Vercel كمسار بديل.

لا تضع \`GEMINI_API_KEY\` في ملفات الواجهة أو المستودع أو التطبيق. اضبطه في متغيرات بيئة الخادم. راجع \`AI_SETUP.txt\`.

## التحديث التلقائي

تعمل الجداول الدورية من GitHub Actions، ولا تحتاج إلى Render Cron منفصل:

- تحديث فهرس الأماكن والحدود كل ست ساعات.
- تحديث مصادر الوظائف كل ست ساعات.
- فحص واجهات الخدمات وأسعار الصرف ومزامنة منتجات التجار المضبوطة كل ست ساعات.

إضافة Render Cron لنفس المهام ستكرر العمل ولا حاجة إليها حالياً. راجع ملفات \`.github/workflows/\` لمعرفة تفاصيل كل مهمة.

## الاختبار والتطوير

يتطلب المشروع Node.js 20 أو أحدث.

\`\`\`bash
npm install
npm test
python3 scripts/test_regional_catalog.py
\`\`\`

تختبر GitHub Actions مزامنة PWA وAndroid، واختبارات JavaScript وPython، ومسارات API المحلية. بعض فحوص الخدمة الحية تعمل على push إلى \`main\` ولا تعمل ضمن فحوص pull request.

## النشر

- تغييرات الواجهة على \`main\` تنشر الموقع الأساسي على Netlify، مع استمرار GitHub Pages كنسخة احتياطية.
- تغييرات المشروع تشغّل بناء Android APK تجريبي عبر GitHub Actions.
- خدمات Render تتبع فرع \`main\` وتقوم بالنشر التلقائي عند وصول commit.
- بناء APK الناتج للتجربة، وليس إصداراً معتمداً للنشر في Google Play.

## حسابات وصلاحيات الإدارة

اختيار صفة العميل أو التاجر والملف الشخصي محلي على الجهاز، ولا يوفر الإصدار نظام تسجيل أو مصادقة مركزياً للعملاء والتجار. مراجعة الإعلانات المشتركة تستخدم \`DALILNA_ADMIN_TOKEN\` على الخادم، وهو رمز إدارة مشترك وليس نظام هوية أو صلاحيات فردية كاملاً.

راجع \`SECURITY_LIMITATIONS.txt\` قبل الاستخدام التجاري.
